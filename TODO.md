# Liquidity Traders — React + Vite + TypeScript Project ✅

## Complete — Rebuilt as Vite + React + Tailwind v4

### Project Structure:
```
package.json          # Dependencies & scripts
vite.config.ts        # Vite + React + Tailwind plugins
tsconfig.json         # TypeScript config
index.html            # Vite entry point
public/
  logo.png            # Brand logo
  background.jpeg     # Background image
  chart mastery.png   # Chart image
src/
  main.tsx            # React entry point
  App.tsx             # Root component with all sections
  index.css           # Tailwind v4 + custom styles
  types.ts            # TypeScript interfaces
  vite-env.d.ts       # Vite env types
  data/
    landingData.ts    # All constants, text, metrics
  components/
    Navbar.tsx        # Sticky nav with hamburger mobile menu
    Hero.tsx          # Hero with 3-step cards, stats, chart
    SangProfile.tsx   # Sang Trades manifesto + execution protocol
    FrameworkSection.tsx  # 3-step tabs with SVG diagrams
    FaqSection.tsx    # FAQ accordion
    ChartMastery.tsx  # Chart mastery section
    Footer.tsx        # Footer with links, disclaimer
```

### Commands:
- `npm run dev` — Start dev server on port 3000
- `npm run build` — Production build
- `npm run lint` — TypeScript type check

### Features:
- Light editorial theme with red (#dc2626) accents
- Plus Jakarta Sans + Space Grotesk fonts
- All sections: Announcement bar, Navbar, Hero, Sang Profile, 3-Step Framework, FAQ, Chart Mastery, Footer
- Interactive tab switching for 3-Step Framework with inline SVG diagrams
- FAQ accordion with ARIA accessibility
- Mobile responsive with hamburger menu drawer
- WhatsApp +254719250533 CTAs throughout
